# 2026-10-27：統一首頁視覺、修正回合按鈕與被遮擋的牌桌提示

## 使用者截圖及設計目標

1. 首頁採深海藍綠底、暖金色字與卡片外框；`/full` 與 `/online` 使用獨立背景、舊版頂欄，寬螢幕時還有全域 `main` 最大寬度，導致外側邊帶色彩不一致。以首頁為基準統一**一般站內頁**。牌局進行中的原生 iframe/安全離開牌局控制不變。
2. 右下方 `取消` 在最後的可選行動其實使回合結束，應明確呈現「結束回合」；若還有其他正常行動則顯示「略過本次行動」，技能選擇或其他原生取消繼續顯示「取消」，回應攻擊時原 `cancel` 承受傷害。
3. `承受傷害` 文字被裁切：原生 `Control.replace()` 依短字「取消」寫入固定 `style.width`；客製文字替換後並沒有重新量測。修正只重新測量原生 childNodes 的 `offsetWidth`，更新容器寬度並呼叫原生 `ui.updatec`，保留 `link='cancel'` 及全部原生事件。
4. 大型 `#grail-phase-hint` 浮層可能蓋住人物、卡牌或確認按鈕；改為嵌在固定戰況條標題的簡短提示，舊的懸浮面板 CSS 停用。打開原生選單時暫隱與之衝突的 HUD。不移除可操作原生對話框。
5. 風之劍聖「風怒追擊」在沒有風系攻擊牌時仍被顯示：原引擎技能 `filter` 僅限制主動攻擊結束；`check` 的手牌檢查供 AI 決策。不得強行加入缺牌禁止條件。改稱「符合發動時機的技能」，在本地手牌確實無風系攻擊牌時補充提醒：「依原規則仍可發動，但額外攻擊可能無牌可用」。提醒只存在個人輔助說明，不洩漏其他玩家手牌，也不介入結算。

## 全角色同類可用性提示稽核（後續擴充）

經核對釘選來源七個角色包中的追加行動排隊、額外攻擊／法術、發動時機與 AI `check`，以同樣的 UI 原則處理**15 項**可辨識的追擊／追加行動技能，而不修改其原始合法性。

- **限定元素或命格**：風怒追擊（風系攻擊）、修羅連斬（火系攻擊）、技之劍意（技類攻擊）、二重劍影（與觸發攻擊同系）。若拿不到確切觸發攻擊牌，二重劍影只提示「需同系」，不得猜測缺少哪一系。
- **限定魔彈或目標**：虛榮掌握（魔彈、可透過相思病轉換，因此不可把無實體魔彈一律當作不可用）、嫉妒追放（攻擊目標必須是手牌數較多的敵方）、劍殘影（需先指定敵方棄牌，追擊目標被限制）。這類技能可能先有效果後才追加行動，缺牌不能阻止發動。
- **一般追加攻擊／法術**：劍影、神聖追擊、瞬・影・殺、戾如泉湧、一擊無念、法力潮汐、附魔打擊、妖精秘術。僅在目前手牌沒有直接對應的攻擊或法術時加說明，並保留後續牌局變化、技能轉換或其他效果。

原生批次觸發技能選擇實際可能出現在 `ui.control > .control > div`，不是 `ui.skills`，所以這批除了展開的輔助說明，也在原生技能選擇按鈕加小型「缺風攻／缺火攻／缺技攻／缺魔彈／缺目標／暫無攻牌／暫無法術／需同系」提示。**這些只是狀態提示，原生 `button.link`、按鈕點擊事件、技能發動條件、原始卡牌結算與行動數均未改變。** 提示撤銷時還原原生 tooltip；缺少可靠卡牌／目標資料時不推測。

不是所有追加行動都需要缺牌提示。例如不屈意志、劍影・斷念等技能會先摸牌、棄牌或產生其他實質效果，不能依當下手牌判定「無效」。掃描與資訊提示不等於 575 項技能已全部完成自然對局的人工驗證，亦不宣稱 15 項就是所有角色技能數。
