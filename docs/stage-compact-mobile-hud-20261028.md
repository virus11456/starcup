# 星杯手機版精簡 HUD（第一階段，獨立開發分支）

## 目的與取捨
使用者實際 iPhone Safari 四／六人局顯示：上方原生選項／暫停／託管、紀錄、說明、牌堆、常駐雙方戰況，外加每一角色的公開手牌數與狀態晶片，同時搶佔有限可視空間。應優先保障「角色、手牌、當前選擇、剩餘回合資訊」可見，把進階資訊設計為可選擇展開，而不是縮小原生卡牌、取消合法控制或改動遊戲規則。

遵循 iOS 對頻繁操作控件建議的 44pt 觸控區，採用 progressive disclosure：常用資訊直接呈現、較少需要的詳細隊伍統計可透過明確標記的「展開」查看。

## 變更
- **公開戰況列**：手機 600px 以下直式預設只顯示目前行動指示、回合、紅藍隊士氣／星杯；增加可點擊、鍵盤與輔助工具皆可使用的「展開／收合」按鈕，在同一份資料節點上切換寶石／水晶與全部統計，沒有額外伺服器讀取或新資料快取。
- **紀錄**：按鈕手機視覺標籤從「本場紀錄 39」改為「紀錄 39」，保留新事件數、原始 DOM 文字、ARIA 名稱、原生日誌內容與事件處理。
- **公開狀態**：角色旁公開晶片採行內緊湊排列，聖盾／十字／水晶／寶石以既有圖示和數值代表；「手牌 X/6」和需要辨識種類的危險／封印標記仍有文字。點選角色的完整說明、原標題及所有 public 信息不移除。
- **隊伍標籤**：在 iPhone 直式省略重複的「隊」字，保留紅藍辨識底色及 ARIA。
- 桌面與橫式手機保留現有版面。絕對不動原生手牌位置、角色座次／點擊、額外行動、抽牌與技能。

## 本階段不得混淆的問題
Issue #8 的特定 iPhone Safari 4／6 人局跑版**尚未完全修復**。這項精簡是改善 HUD 密度與資訊層級，不代表所有裝置的角色／徽章碰撞已根治；舊 PR #9 的手機模擬驗收仍會失敗/需調查。封印師技能 crash v59 已另行發布，該引擎修復不應在此改動。
