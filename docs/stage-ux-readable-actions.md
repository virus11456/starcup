# UI 可讀性與行動結束標示（本地待整合階段）

日期：2026-10-26（台北時間）。本階段目前**未部署 Cloudflare，未合併 main，未變更正式資料**。

## 使用的 UI/UX 技能

依使用者要求使用 <https://github.com/nextlevelbuilder/ui-ux-pro-max-skill>：讀取其 `SKILL.md`、`references/pro-rules.md`、`references/quick-reference.md`，並實際執行 `scripts/search.py` 的遊戲設計系統、徽章換行與手機文字可讀性檢索。保留星杯既有深青／金色視覺、直式角色牌及原生戰鬥介面；優先處理小字、窄螢幕溢出、互動區辨識與清楚狀態。

## 行為修改

- 在 `xingDong` 最後一個可略過的普通攻擊／法術行動，把原生取消鈕呈現為「回合結束」。判定讀取原生 `event.action`、行動事件名、玩家剩餘行動與額外行動佇列。額外行動被先行移出佇列時，也允許最後一個有效行動呈現此文案。
- 仍有其他行動、已選中的技能可返回、強制回應、自訂確認與承傷選擇時，保留「取消／返回／承受傷害」原意。**不改 `button.link`、onclick、原生 `chooseToUse` 結果或任何卡牌規則**。
- 「回合結束」鈕以獨立 `data-grail-action="end-turn"` 呈現易辨識的深綠金邊。

## 顯示調整

- 首頁、模式入口、房間與說明文字、圖鑑／教學／規則，主要說明統一到約 16px，次級標籤約 14px，增加行距；導航與互動控件保留至少 44px 可操作高度，鍵盤焦點有明顯外框。
- 320／390px 下導覽可換行、長說明可自動折行、卡牌圖鑑自適應一或二欄，避免卡片與設定表單被擠到螢幕外。
- 完整擴充角色選擇與說明、多人建立／加入房間表單增大字級，窄螢幕重新排列；戰鬥原生手機工具列提升至 13px，操作鈕提升至 16px，玩家前的盾／十字／水晶／寶石狀態徽章提升至 12px 且增大空間。
- 保留 `prefers-reduced-motion` 既有處理，不另加昂貴特效或新圖庫。

## 本地驗證與限制

- `node --test tests/card-skin.test.mjs`：新增最後一般行動、最後額外行動、仍有其他行動、技能返回與原生連結不變等回歸案例，通過。
- `postcss.parse`：六份改動的 CSS 全部可解析。
- `npm run verify:local`：以包含最後額外行動判定與完整狀態守衛的最終版本**重跑，exit 0**。本地 Next/Vinext 建置、應用與引擎、10 項 Cloudflare Workerd/SQLite 測試、型別、64 項已建置網站 HTTP/安全邊界檢查全數通過。
- Cloud Browser 的 390px 舊版正式網站已作基準畫面檢查，**本地修改後的真實瀏覽器多尺寸視覺驗收尚未完成**：遠端瀏覽器尚無法連接本機環境，不能把 CSS 語法／單元測試當成新畫面的截圖驗收。

## 整合發布前

1. 和房主關頁接手等未完成的重大工作一起完成整合階段；若其後有任何程式變更，在整合結果上重跑 `npm run verify:local`。
2. 在可載入新版的瀏覽器檢查手機 320／390px、短螢幕與橫向 844×390、平板、桌面，以及首頁、圖鑑、教學、完整擴充與原生對戰。
3. 確認只在最後可略過的行動按鈕顯示「回合結束」，實際按下仍順利走原生棄牌／結束階段；多行動與技能回退不誤標。
4. 大階段一次發布到 Cloudflare 後重新驗收邀請與房主恢復，再決定 Vercel 是否可退場。未驗收前不合併會觸發舊部署的 main。
