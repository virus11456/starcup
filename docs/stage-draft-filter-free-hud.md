# 2026-10-27 iPhone 選角與行動提示位置修正

## 實機回報
1. 選角視窗內原生圓形 #roundmenu 浮在文字說明和角色卡上。
2. 「收藏／最近／戰技殿堂／幻影聯盟／鮮血議會／神聖教廷／篩選」分類列因原生 DIV 絕對定位與字寬被壓縮，中文字被迫逐字斷行。
3. 技能觸發時被鏡像到比分列的提示（例如風怒追擊的額外攻擊確認）覆蓋了士氣、寶石、回合文字，不易確認選擇。使用者希望改放場景中下方、手牌與確認按鈕上方的空白區。

## 修改
- 選角模式 `#arena.choose-character` 時只隱藏原生 `#roundmenu`（不移除節點，不更改引擎控制鍵或事件）；對局及其他選擇保留正常圓形選單。
- 原生選角篩選 `.dialog .caption.pointerspan` 中的分類列使用 flex 單行，所有 `.tdnode` `flex:0 0 auto`、`white-space:nowrap`，字級及按鈕高維持可觸控；超寬時橫向平滑捲動，不再讓名字硬切成多行。原生第二層過濾列表以 `style.display=none` 切換的隱藏狀態必須保持，點「篩選」才顯示。角色卡點選、長按與篩選 click/touchend 維持原生。
- 純文字行動提示改掛到獨立 `#grail-hud` 的 `#grail-phase-hint`，不再插入戰況表標題列、絕不佔掉士氣/血量/星杯顯示。
- `chooseActionHintTop` 根據 viewport、安全的比分板底部、公開角色範圍、原生 `#control`、自己手牌區選最近安全位置，預設偏畫面下半部（手機直式 56.5%、短橫式 61%）且只在純文字可見時顯示。保留 `pointer-events:none`；真正含卡牌、技能/應戰選項的原生互動視窗不搬動。
- 提示使用高對比金色文字、深色底、約16px手機字級及兩行可換行的水平排版；橫式縮至 <=54% 視窗寬。

## 驗收
- 新一局 iPhone 直式選角：圓形浮動選單不壓住角色說明，分類一整行可左右滑，按篩選才展開第二列。
- iPhone 直式觸發額外風系攻擊：提示位於中央牌桌空位、戰況所有數字仍能看清、確定/取消/手牌不卡住；長文字不過度增高。
- iPad 橫式/桌面：角色與工具列仍可操作；無法找到空位時採最近位置，不改選牌法則或將任何私有資訊洩漏到提示。
- Cloudflare 建置與回歸測試成功後才算上線。實體 Safari 還需再次確認畫面。
- 沒有新增付費產品、不改 Vercel、房主架構、角色卡牌規則或 Durable Objects 房間資料。
