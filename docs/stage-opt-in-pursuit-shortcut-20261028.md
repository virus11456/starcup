# 單人缺牌追擊快捷（2026-10-28）

承接[全角色詢問稽核](audit-all-character-prompts-20261028.md)。風怒追擊目前沒有風系攻擊牌仍可合法發動，因此不修改原生資格判斷，而提供玩家可自行開啟的「替我取消」快捷。

## 使用方式與範圍

在牌桌「說明」內展開「追擊快捷」，勾選「單人：自動略過缺牌追擊」。**預設關閉，不儲存設定，重新載入即關閉**。開啟說明面板時暫停快捷，方便查看技能及關閉設定；「下一次保留詢問」可讓下一個符合快捷條件的窗口維持手動，且同一窗口不會在下一次 HUD 更新又被取消。

快捷只考慮風怒追擊、修羅連斬、技之劍意、二重劍影與劍影這五個已核對的純追加行動。檢查的是目前手牌，不把「缺牌」寫進技能的 filter。角色有轉換牌、隱藏／虛擬牌、特殊區可用牌、系別／命格改寫、未解析技能或不明觸發牌時，仍保留原生詢問。例如游擊士具有精靈的劍舞，二重劍影不會因缺少對應實體牌而自動略過。

這不是全角色自動代打。神聖追擊的治療、不屈意志的抽牌及劍氣、劍影・斷念的抽牌、瞬・影・殺的狀態、戾如泉湧的指示物，以及指定牌代價的 cost 等，均不在快捷範圍。全角色稽核清單仍保留這些區別。

## 原生操作及保護

- 僅在本機玩家自己的行動階段、已暫停等待輸入的原生 chooseBool／arrangeSkill chooseControl 窗口操作，而且必須找到該窗口唯一、可見的原生取消按鈕。
- 單技能依原 trigger 事件辨識 ID；多技能「取消」會拒絕整組，因此**只有整組全部都是上述五項、且每項目前皆缺對應牌時才取消**。任何未知技能、混合效果或仍有對應牌的追擊都讓整組維持原樣。
- 只呼叫原本 `ui.click.control`；不自己寫 event.result、不呼叫技能 content、不扣資源、不重建事件、不直接 resume、不重排技能。原生雙擊防護忽略點擊時不顯示「已略過」，並於下一次狀態檢查後才可能重試。
- 每次操作前重新讀取手牌與當前事件，事件已更換、已有回覆、背景分頁、玩家暫停、託管、遊戲結束時不操作。
- **多人一律不執行快捷**，並停用開關；不繞過房主斷線輸入保護，不代送原生網路答案。未更改 WebSocket、房間或其他玩家資料。

## 修改檔案

- `vendor/noname/overrides/grail-prompt-shortcut.js`：保守判斷、原生取消與逐分頁設定。
- `grail-bridge.js`：掛入既有 HUD 更新及卸載清理。
- `grail-inspection.css`：說明面板中的設定，短橫式可獨立捲動，操作區 44px。
- `tests/prompt-shortcut.test.mjs`：13 項回歸，包含整組拒絕、轉換／特殊區／繼承、手動覆寫、過期事件、雙擊防護、多人停用及 UI 開關。
- `scripts/check-browser-layout.mjs`：建置後桌面、Chromium 觸控與 WebKit 手機設定開關／覆寫／幾何驗收；支援指定本機瀏覽器及 Playwright 路徑。原生選項層級等動畫結束後才量測，判斷標準不變。

原始角色、牌組、技能 filter/cost/content、資源與行動數均未修改。
