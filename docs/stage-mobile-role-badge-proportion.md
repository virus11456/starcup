# 2026-10-27 手機角色大小和狀態標示比例

依照 iPhone 實機畫面，原 1.20 的角色立繪仍明顯小於下方「手牌 4/6」標示，對戰主要視覺不協調。

本次把 iPhone 直向的非自己角色原生 DOM scale 改為 1.38，iPad 直向改為 1.22；短橫式不強制放大。保留原生角色、技能目標和座位，不建新卡片或擴大下面的手牌區。

將外側「手牌 4/6」狀態標示壓縮（取消重複圖示、單行、iPhone 最大108px），數字仍以17px高對比顯示；聖盾、水晶等指示物維持原本標示。左右邊界縮放的 transform-origin 增加18px穩定區，避免重算座標時反覆跳動。

整套回歸驗證角色 CSS、手牌徽章、縮放原點和標籤寬度；仍需以實機 iPhone/iPad 驗收不同角色密度下是否遮到資訊列。未改技能、房主模式、Cloudflare 免費方案相容配置或 Vercel。
