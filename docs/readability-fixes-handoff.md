## 原因與修改

- 指示物空白項目來自固定引擎 `Player.buildExtra()`：每位角色都預先 `player.mark(" ", { mark: get.linkintro })`。即使沒有橫置，這個沒有名稱的原生節點仍存在。閱讀面板以前只看 `.mark` class 而誤列「啟用中」。現在辨識 `player.node.link`，只讀原生公開 `isHengZhi()`／`isLinked()`；未橫置不列出，橫置時明確顯示「橫置／已橫置／公開狀態」。重置後消失；不呼叫 intros、不讀私人 storage。
- 其他沒有可讀名稱的空白節點也不產生空標題。有明確名稱的普通標記、0 數量、元素／能量與專用蓋牌保持原顯示規則。未捏造未知效果或替原引擎改數值。
- OpenCC 的台灣慣用語轉換把「的士氣」前兩字誤當作「的士」（taxi），造成「計程車氣」。建置轉換時以完整遊戲用詞「士氣／士气」分段保護，避免跨詞誤判；其他文字照常轉換，真正的「的士」仍可翻成「計程車」。既有網址、屬性、資產名與程式結構保護保留。
- 固定引擎的神之庇護、死鬥、凋零三處說明已正確生成「的士氣」；不是只針對勇者的畫面替換。遊戲規則、原始圖片與 CSS 未更動。
