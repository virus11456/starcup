## 可重複執行的核心版多人整合測試

先設定本機 `.env.local` 並啟動 `npm run dev -- --port 3107`，再執行：

```bash
node --env-file=.env.local scripts/check-multiplayer.mjs
```

測試會建立一間私密測試房，使用四個獨立 Cookie 會話驗證加入、準備、開局、手牌隱私、過期版本衝突、非法出牌、跨站請求與重新連線。設定 `GRAIL_TEST_REPORT` 可保存測試結果；報告不包含 Cookie、手牌或金鑰。`GRAIL_TEST_URL` 可指定已完成後端設定的部署網址。

整合測試會留下它建立的房間，並印出房間代碼。只清理該次測試產生的代碼；不可清空所有房間。

十局完整核心連線測試：

```bash
GRAIL_TEST_URL=https://star-grail-online.vercel.app GRAIL_TEST_REPORT=outputs/ten-matches.json node scripts/check-live-matches.mjs
```

此測試建立三間私密房（4／6／8 人），只使用公開 API 回傳的合法行動與各玩家自己的手牌，執行十局至勝負結算。檢查牌張守恆、回合與隊伍同步、私密手牌及再次開局。這是核心模式的驗證，不涵蓋完整擴充角色技能。
