# 2026-10-27 長按手牌防誤觸與 iPad 直向檢視修正

## 問題
手機 Safari 在長按手牌後可能連續送出 `pointerup`、`touchend`、`click` 和 `contextmenu`。先前的 `grail-detail-view.js` 在 850ms 內攔截「所有手牌／角色」上的這些事件，並非只有原本被長按的那個節點，可能導致快速選牌或選目標感覺失靈。

放大卡牌視窗使用 `max-width:700px` 才改成上下堆疊，導致 768px、820px 等直向 iPad 仍使用窄雙欄，說明文字難以閱讀。

## 修改
- 長按成功開啟放大視窗後，記住確切的原生卡牌／角色／選角卡節點；只抑制該節點的尾隨 `pointerup`／`touchend`／`click`／`contextmenu`。
- 同一期間其他手牌與其他角色不會被這個攔截規則擋掉。若指向新的互動目標，仍保留原生事件傳遞；放大視窗開啟時其遮罩本身繼續負責防止背景互動。
- 關閉／銷毀放大視窗時清理事件監聽與攔截狀態，不影響其他原生選牌處理。
- 直向螢幕 CSS 寬度 900px 以下使用「完整人物／卡牌在上、文字說明在下」，包含 iPhone、iPad mini 和 768／820px iPad；iPad 橫向與桌面維持左右分欄。
- 補測按住牌後自己與其他牌／角色的四種事件，以及 iPad 直向斷點 CSS。

## 不更動
不修改傷害、技能、牌庫或多人房間資料；不更換房主架構、不啟用 Cloudflare 付費服務、不改 Vercel。自動測試不能取代 Safari 真機驗收。
