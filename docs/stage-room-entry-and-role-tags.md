## 本批修改

- 首頁與單人 `/full` 的準備頁、對戰頁共用 `app/site-brand.tsx`，同一份字標、標語及既有響應式 `site-brand` 樣式。單人頁移除衝突的字級／顏色覆寫；離開本機對局的確認保留。
- 原生角色按鈕建立及 refresh 時加入定位標籤，單人候選與多人全角色選取共用。涵蓋 68 現行角色及 16 舊版變體。依固定技能與角色介紹明確整理「戰鬥／法師／輔助」，必要時加「控場／守護／資源」，最多兩項；例如魔劍士為戰鬥、戰鬥法師為戰鬥／法師、聖女為輔助／守護。這是玩法定位參考，不冒稱官方職業分類，不以角色名猜測，不把勢力改成職業。鑄律者與紅衣主教切換時會更新定位。
- 上手難度直接讀取固定原引擎的星等。`characterSort` 明定 3／3.5／4／4.5／5 星，角色欄位將半星存成 `3/4` 或 `4/5`；原生 `get.character()` 轉為 hp／maxHp，再取平均顯示。沒有另造評分，也沒有把星等當成角色強度。保留半星填色與數字，讀屏可讀「上手難度 3.5 星，滿分 5 星」；舊版依該版原始數值顯示。另抽查參考百科風之劍聖 3★、聖女 3★、劍帝 4.5★ 與引擎相符。
- 選角卡在原圖下預留 44px 的兩行定位／星等列，依既有觸控縮放同步調整，星號與數字限制在 76px 原卡寬內；只在選角時隱藏重複的原生 hp 星等節點。保留原卡片、圖像、姓名、勢力、點擊及角色互斥規則。定位與難度說明出現在選角對話框中；不增加網路請求或資料庫寫入。實機畫面尚待驗收，不能以邏輯測試宣稱沒有跑版。
- 本場 log 原本在「紀錄」：手機工具列位於「說明」左側，桌面在右側說明下方。新標籤改為「本場紀錄」，仍顯示未讀數、搜尋與較早紀錄。來源是原生公開 sidebar，包含引擎已記錄的出牌者、目標、牌名、技能及結算；不讀隱藏手牌，也不冒稱每項技能都有完整 log。最多保留本頁最近 1,000 筆，重新整理後重新累積，未改成永久資料庫紀錄。
- 建房回應遺失的根因：前端每次重新產生座位識別，後端每次產生隨機房碼。現在於 HTTP 前在同分頁 sessionStorage 保存開房識別及設定，網路／解析失敗、取消、保存座位失敗時可重試；24 小時內相同設定沿用，設定改變或成功後的新開房使用新識別。沒有把憑證放進邀請網址或 localStorage。
- 後端以帶伺服器密鑰的 HMAC 為這次開房產生穩定 8 碼，忽略客戶端指定房碼。僅回收同房主、同設定、未啟動且未過期的房間，保留已加入朋友；已附掛原生引擎、進行中、關閉或設定不同時回傳 410，不覆寫／重開原牌局。前端只有明確的終止回應才清除待重試識別，顯示錯誤後讓下一次明確點擊建立新房間。
- Cloudflare 每房 DO 先查既有房間，再保留每 IP 開房額度；跨 DO RPC 後重新讀房間，防止併發請求覆寫。每 IP 的 reservation 以識別去重，仍計入前版 attempts，保留每小時 5 間限制與既有清理 alarm。正常已完成的重試只讀房間，不再保存房間或更新大廳；切換網路 IP 不會另開一間。
- 保留的 Next／資料庫介面同步使用穩定房碼，重複插入衝突時查回並核對原房間，不用 upsert 覆寫。只有本機 HTTP fixture 驗證，沒有變更 Supabase 資料表、權限或線上資料；此舊介面原有跨不同新房間的限額併發限制未重新設計。
