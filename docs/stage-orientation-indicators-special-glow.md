# 2026-10-27：橫直版狀態欄、指示物位置與專屬金光修復

## 使用者實機截圖問題
- 橫向狀態提示佔住左側角色卡；直向提示仍在中央角色旁，搶佔視線。
- 右側玩家的「聖盾／言靈／祕術」等公開指示物貼著右邊界溢出，且可能互相擠壓。
- 自己的印刷專屬攻擊牌雖已在抽牌時有金邊，但亮度不足，難以在深色背景辨認。

## 實作
1. `grail-action-hints.js` 的純提示辨識不改動原生互動、技能、卡牌操作；只鏡像公開純文字到 `grail-scoreboard` 原有標題列的 `#grail-phase-hint`，原生被鏡像的純提示視覺隱藏。有互動元素的對話框不鏡像、不隱藏。戰況面板未出現時保留原生提示退路；空字串不顯示。透過 CSS 區分 iPhone 直式與短橫式。
2. `grail-player-indicators.js` 新增純函式 `placeIndicatorStrip(rect,viewport,size,occupied)`：左右夾在可視畫面 8px 內、優先角色正下方、不夠空間上移、避開已擺放的其他狀態列。不動原生角色 DOM 與指示物本身，只定位旁邊的唯讀 chip。直式 600px 以下採窄版垂直排列；短橫式則縮小高度並保持角色席位在畫面內。
3. `grail-polish.css` 對「**目前角色本人持有且符合印刷專屬技能的攻擊牌**」原本金框 `::after` 增加 2.6s 柔和呼吸光效；不改選牌抬升或指令、不擷取點擊、不把普通牌變金。設定 `prefers-reduced-motion: reduce` 時禁用動畫但保留靜態亮金圈。

## 自動測試與驗收
- 純提示和原生技能選擇不互相干擾、有字/空字正常；橫直向 CSS；右端 viewport 裁切檢查及兩組 chip 避讓；金光與 reduced-motion。
- 上線前必須通過 Cloudflare 應用、原生引擎、型別檢查與 Worker 部署。
- 但自動測試無法取代**實體 iPhone／iPad Safari 真機**；尤其需要新牌局查右側多枚狀態、橫向攻擊與縱向四張手牌，不應在進行中的房主頁重整。
- 保留原生 noname、Cloudflare 免費方案相容 Workers/DO/Assets、房主模式；不升級付費、不動 Vercel。
