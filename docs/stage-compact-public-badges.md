# 2026-10-27 多指示物擁擠時優先顯示手牌數

## 痛點
玩家牌桌可顯示聖盾、水晶、中毒、橫置、手牌張數等公開標記。當手機直向放大角色到 1.38 倍或八人對戰，整組公開狀態列可能放不下；上一版直接取消整組並恢復原生牌數，容易讓「手牌幾張」失去原本一致的水平表示。

## 變更
- 優先嘗試完整公開指示物列表。若該整組因真實螢幕碰撞無法放入，試只呈現公開 **手牌數** 的緊湊外側標示，不移除角色本身既有原生聖盾、水晶等圖示。
- 仍然使用 `placeIndicatorStrip` 的矩形碰撞檢查，絕不遮蓋角色、士氣欄、確定/取消按鈕、自己手牌或別人的外側標籤。
- 緊湊模式在 400ms HUD 更新中保留短暫狀態，約三秒後或版面/其他玩家狀態有變時重新嘗試完整狀態列，減少整組 DOM 每次重建造成的閃動。
- 若連緊湊手牌數都沒有安全位置，不隱藏原生 Noname 的公開計數。引擎原本計數和隱藏手牌資料都不作任何變更。
- 新增完整優先、擁擠降級、無空間恢復原生資訊、緊湊狀態穩定的回歸測試。

仍須真實 iPhone/iPad Safari 驗收。現有完整遊戲規則、Cloudflare 免費方案相容 Worker/DO、房主模式和 Vercel 設定均不更動。
