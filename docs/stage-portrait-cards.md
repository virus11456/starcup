# 直式卡牌：本機完成，待下一階段集中發布

2026-10-26（台灣時間）。使用者在進度詢問後要求「卡牌幫我做成長方形，正方形很不好看」。沿用分階段完成、本機檢查、備份 GitHub，再集中部署的方式；本批不單獨推正式分支。

## 修改

- 啟動採用原生 `cardshape: oblong`，單人與多人一致，也納入每頁隔離的啟動設定，舊儲存設定不會把新局改回方形。
- 手牌與出牌節點使用直式約 5:7 比例：桌面邏輯尺寸 104×144、手機視窗尺寸 76×108，結算／選牌視窗 90×126。手機保留橫向捲動與 8px 選取抬升，橫向手機同樣走原生 scrollh 觸控路徑。
- 桌面保留原 fan 與 104px 寬度計算；加高容器、預留原生 20px 選取抬升與捲軸空間。手機手牌列由 96 加高至 132px，操作列底距由 116 改為 152px；提煉面板底距取同一變數再加 44px 操作列與 12px 間隔，避免只拉長牌而重疊操作。
- 短橫向牌桌同步多留 36px 手牌區，自己的角色仍對齊底列。說明縮圖由 72×72 改為 72×100。角色牌、圖鑑與既有卡牌動畫本來即為直式，保留原比例；指示物／附著牌不套用大卡尺寸。
- 保留原美術、節點、點擊、技能與規則；圖片使用等比例 cover／contain，不拉伸圖像。不新增伺服器寫入或下載資產。
