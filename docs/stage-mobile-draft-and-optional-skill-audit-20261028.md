# 手機選角裁切 + 全角色額外行動提示稽核（2026-10-28）

## 問題與修復範圍

手機選角視窗原先由 Noname 原生 Dialog 建立，包含角色卡、下方「選擇座位」和原生 `#control` 的「更換／自由選角」等操作。先前 `grail.css` 以 `top:46%`、`height:auto` 配合畫面外的 `#control`，在 Safari 可視高度縮短、字體放大時，角色卡清單加上座位列比對話框還高；下方文字被裁切，選項與按鈕重疊。上一版只有 390×844 桌面 Chromium 縮尺寸驗證，沒有覆蓋小 iPhone WebKit。

- 以真正手機直式 `@media` 限定修復，確保角色選擇 Dialog 完全留在 `#arena` 的可用高度內，底部預留原生控制列及安全區。
- 只有包含角色卡候選的選角對話框改成三段內容：簡短說明、**獨立可捲動角色卡清單**、固定可視的原始座位選擇。座位仍使用原引擎 `table.add-setting .tdnode`，不增刪或重建座位按鈕。
- 原生的「更換／自由選角／確定」及其原有事件處理仍在原本 `#control`，只在畫面上和 Dialog 分開。
- 目前增加 Chromium + WebKit 375×667 四人、390×844 六人自然開局選角幾何檢查，使用觸控、3× DPR 與原生座位選項，檢查可視範圍與上下切割。

## 技能詢問：規則限制與現行 UX

**風怒追擊**（十週年風之劍聖）原始 `fengNuZhuiJi.filter` **只檢查 `!event.yingZhan`**；`check` 中檢查風系攻擊牌只供 AI 決策，`content` 為加一次風系限定的攻擊行動。使用者沒風系牌時「仍可發動」是原規則合法選擇，不是意外可執行牌。直接改 `filter` 或隱藏合法按鈕會刪除原有選擇，且可能錯過其他當下觸發的摸牌／換牌／轉換效果。**不能為了少詢問就默默改原始規則。**

稽核範圍是釘選的七個角色包：十週年、異端業火、神子創臨、終末禱鑄、特典，以及三／四版的舊角色。通過 AST 自動盤點每個包中 `addExtraXingDong`、`extraXingDong.push`、`addGongJi`、`addFaShu`、`addGongJiOrFaShu` 等賦予行動的技能，並區分「只是追擊／追加行動」與「同時消耗資源、抽牌、治療、傷害、棄牌、加減指示物」者。十週年、異端、神子、終末、特典中有多種多重效果的例子，不能只用是否持有指定系牌當成觸發合法性條件。

既有 15 項只讀 UI 提示，包含風怒追擊、修羅連斬、技之劍意、二重劍影、虛榮掌握、嫉妒追放、劍影、神聖追擊、瞬・影・殺、戾如泉湧、一擊無念、法力潮汐、附魔打擊、妖精秘術、劍殘影。本次加強「**只有純追加行動而目前沒有相應手牌時，可按『取消』略過；原規則仍可選擇發動**」的資訊，不新增另一層對話框、不取代任何原生選項、也不對含有其他效果的技能建議自動取消。針對原生技能選項的 ARIA 名稱一起更新，方便 VoiceOver 辨識提示；可用牌回來時完整復原。

**明確不做**：沒有證據就隱藏技能、阻止可發動時機、扣資源或替玩家自動按取消、修改角色及物理卡牌來源。若之後要真正「自動略過無牌追擊」，必須另立不改規則的可關閉使用者快捷設定，還要驗證多技能先後順序與轉換、摸牌是否可能讓追擊有用；不屬於本次未經驗證的變更。
