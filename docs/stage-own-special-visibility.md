# 疾風技與專屬攻擊卡的金色提醒

2026-10-26，本機待整合；使用者回報 iPhone Cloudflare 對局：風之劍聖手上雷光斬印有「疾風技／精準射擊」，但沒有一眼可見的特殊色提醒。

## 修正

- 專屬卡牌標示以卡片 `duYou` 印刷技能和**當前角色** `lib.character` 所列天生技能的交集決定。去掉冗餘的 `lib.skill[id].duYou` 執行階段條件；技能物件尚未註冊或被包裝，不應使卡面提示失效。
- 只套用於自己手牌中的攻擊卡，保持 `infohidden`、移出手牌、換角色時的標示清理。角色不具備卡上任何專屬技能時仍是一般卡色；如果卡片印有兩個專屬技能，各自擁有其中一個技能的角色都可獲得自己的金框。
- 原先細弱的金框改成 4px 明亮金色外框＋卡內金色環，適應 iPhone 橫向可捲動手牌可能裁掉外部光暈的情況；卡名和右下技能說明也改以金棕底色強調。已選中的牌仍保留薄荷綠選取光環。
- 此修改只有外觀標示與檢測邏輯，不更動牌卡、角色技能、能否出牌、目標或攻擊傷害。
