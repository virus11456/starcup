# 2026-10-27 擴大角色後公開指示物避免遮擋

新版 iPhone 角色照片放大 20% 並改為外側水平「手牌 x/y」後，狀態列原本只避開其他狀態列，不一定避開其他放大的角色、血量、比分板和原生操作區。現在 `placeIndicatorStrip` 先測實際放大後的角色矩形，按下方、上方、右側、左側順序選安全空間，不能放到本人的角色、其他角色、戰況列、手牌/控制區或已佔用的狀態列上。

極窄畫面若沒有任何安全位置，外側狀態列暫不顯示，但保留原生計數，不會先把「牌數」藏掉；選角階段、席位移除或元件銷毀時也恢復原生計數。全部資料仍取自 noname 已公開的指示物與 node.count，沒有讀取對手手牌。

新測試包含強制衝突、左右定位、安全邊界和在未成功定位時不得隱藏牌數。自動測試不等於實體 Safari 驗收。沒有修改角色技能、房主模式、Cloudflare 免費相容 Worker 或 Vercel。
