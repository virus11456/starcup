# 手牌、角色技能與指示物說明：待發布交接

使用者要求三者顯示更清楚。此次沿用同一原生引擎及牌面，不改技能效果、消耗、發動時機、選牌或角色規則；單機與多人使用相同的 `grail-bridge.js`，所以共用此次閱讀介面。

## 玩家使用方式

上方原「提示」位置改為「說明」，開啟後提供四類：

- **手牌**：依實際手牌順序顯示牌名、系別、命格、基本效果及牌上的獨有技。與自己現有角色技能相符的標記加金色「本角色獨有技」標籤，其他標記仍列出。這不是現在一定能發動的保證，原選牌／條件／確認操作不變。
- **角色**：選擇牌桌上已公開的角色，完整顯示技能名稱、時機、條件與效果；沿用引擎動態技能文字及停用狀態，不另寫一份遊戲規則。
- **指示物**：顯示公開指示物名稱、現有數量、可取得的上限、原說明及文字中相關的角色技能。標記與個人能量兩個原生容器均讀取。若原引擎沒有獨立用途文字，清楚導向角色技能；不臆造效果。蓋牌只讀公開數字，不讀私人內容。
- **本回合**：保留原本階段提示、可選手牌／目標及角色技能摘要。

說明區正文設定為 16px、技能名稱 17px、牌名 20px、數量 22px；高對比色、分段與可捲動閱讀區。手機直向留邊，矮橫向擴大可用高度。工具列沿用原位置，不多塞一個按鈕，並修正窄版收合說明與「紀錄」可能重疊的寬度。原手牌名稱／獨有技字樣與牌桌指示物數字提高對比，原牌面與指示物節點未移動。

查看不出牌、不發動技能，也不暫停牌局。資訊改變時顯示「資訊已變動 · 更新」，保留正在閱讀的內容與捲動位置；點更新或重新開啟才重讀。Esc 關閉並返回入口焦點；閱讀區的 A／空白鍵不會傳到引擎觸發託管／暫停。面板收合時不持續讀取手牌。
