## 此批修改

- 公開戰況改為盾牌／杯／寶石／水晶四種 SVG 圖示及數字；紅藍隊與我方標記保留，完整意義放在可及性標籤、title 與提示說明。手機牌桌頂端預留由 CSS 的 208px 改成 130px（套用既有縮放），這是樣式設定差異，尚非實機量測。
- 新增「紀錄」入口，觀察原生 `ui.sidebar` 公開紀錄，僅讀取 `textContent`，不改 `game.log`、規則或手牌資料。保留本頁最近 1,000 筆，可搜尋、每次載入 100 筆較早紀錄；新動作只更新提示，閱讀及載入較早紀錄時不插入新項目。重新整理後重新累積，不保存到資料庫。
- 紀錄與提示使用既有手機工具列位置，紀錄面板有關閉及 Escape；橫向小高度使用緊湊排列。暫存分頁 `pagehide.persisted` 不再銷毀戰況、提示及紀錄 HUD。
- 外層 `/online` 保存此分頁原房間的導航資訊，座位憑證沿用 `sessionStorage` 原 key。一般玩家在相同房間 URL 重新整理或歷史返回時，使用原憑證 join，再走既有原生 reinit；正常新造訪只顯示「重新連接牌局」，不自動跳舊牌局。不同房間邀請不會被舊房間覆蓋。
- 「邀請朋友」按鈕開啟可關閉視窗，含完整連結、房間碼、系統分享、複製及手動選取備援。連結只攜帶房間碼；密碼驗證後保留 `/online?room=…`，填暱稱即可加入。沒有把網站密碼或座位憑證放進 URL。
- 房主增加瀏覽器離開提醒（瀏覽器不一定顯示）；若偵測為原房主，不建立新引擎覆蓋舊局，而是說明回原分頁／結束舊房間。**這不是房主重新整理恢復或伺服器接手**；真實房主事件堆疊仍在瀏覽器，系統回收分頁後仍無法續行。
- 中繼永久停止時標記 native ws 關閉、清空待送訊息並忽略後續 engine send。暫存分頁仍保留未確認訊息及 epoch，與永久關閉分開。解決致命錯誤後仍無限累積無法傳送訊息的本機問題，沒有宣稱正式記憶體或配額節省數字。
- 準備引擎時直接略過既定未啟用檔案，不再先複製再刪除，避免同步工作區殘留未啟用角色檔。角色清單與規則未改。
