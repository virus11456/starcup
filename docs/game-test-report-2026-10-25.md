## 完整擴充模式的瀏覽器檢查

已操作正式爆食少女出牌，確認可選手牌與合法目標提示跟隨選擇更新；交給 AI 後，游擊士、封印師、劍帝等角色能繼續進行攻擊與技能結算。

八人場已確認可選角並進入第一個角色回合；頂部導覽水平排列，角色回合進度正確顯示。展開技能說明後再選牌，說明仍保持展開。

瀏覽器實測發現兩個問題並修正：舊版引擎樣式覆蓋牌桌寬度，導致右側提示遮住角色；完整擴充對戰在勝負結算時，嘗試把重播寫入未開啟的 IndexedDB。前者提高版面規則的優先順序；後者在本機模式停用重播保存，並在結算寫入前檢查資料庫是否存在。

修正後的擴充引擎 14 項自動檢查全數通過，包含實際結算分支在 IndexedDB API 存在但資料庫未開啟時不會拋出錯誤。完整擴充從開局到結算的瀏覽器重跑尚未完成，不列為通過對局。
