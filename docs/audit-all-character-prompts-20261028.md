## 風怒追擊的結論

**沒有風系攻擊牌，通常應自行取消風怒追擊；但不能把「目前沒有風牌」直接改成技能不合法。** 風系法術牌也不能直接支付風系攻擊。減少無用詢問是介面優化需求，不能等同於修改發動資格。

- [原始技能](https://github.com/RancherJie/noname_xingbei/blob/bd227231b6edeba5b32f906673b9f3cb0091b90c/character/shiZhouNian.js#L131)：發動時機為主動攻擊結束後，每回合一次；`filter` 沒有手牌條件。效果新增一次限定風系攻擊牌的行動。`check` 才檢查當下是否有風系攻擊牌，供 AI 決策。
- [風之劍聖 FAQ](https://xingbeichuanshuobaike.webnode.tw/角色詳情-風之劍聖/)確認這項追加攻擊有風系限制，疾風技與劍影沒有系別限制。
- [玩家整理規則書：技能發動條件與效果](https://xingbeichuanshuobaike.webnode.tw/遊戲指南-規則說明書/)區分發動條件與不完全效果：明確的代價必須滿足；效果未完整實現未必禁止發動。沒有合法目標又是另一種情況。這是玩家整理資料，不能冒稱官方對全部擴充的個別裁定。

本次新增的執行測試直接呼叫生成引擎：只有火攻或風系法術時，風怒追擊 `filter=true`、AI `check=false`；發動後的牌型過濾器拒絕火攻、風系法術及被禁用的風攻。沒有新增能量費用。這證明目前的詢問與出牌限制分屬兩個檢查點。

不能只因 AI 不建議就代替真人取消；先觸發其他抽牌、轉換或狀態改變，也可能影響稍後的行動。是否存在這些互動要逐情境驗證，不把抽象的「可能轉換」當作每位角色都能轉換的證據。

## 應分開判定的情況

| 類型 | 檢查結果／例子 | 處理結論 |
|---|---|---|
| 先取得行動，稍後才出牌 | 風怒追擊、修羅連斬、技之劍意、二重劍影 | 當下缺對應牌不等於發動不合法；可提示缺牌及取消 |
| 明確需要能量 | 劍影、法力潮汐 | 保留能量門檻；水晶費用可由寶石支付，不能只看水晶數量 |
| 指定牌是發動代價 | 水影、貫穿射擊、替身玩偶、魔能反轉等 | 必須由原生 cost 選到合法代價；不可比照純追擊而允許無代價結算 |
| 明確目標不存在 | 風之潔淨、懲戒 | 原生 `filter` 同時檢查可選目標；實測無基礎效果／無其他有治療的角色時不開放 |
| 棄牌只是效果 | 神聖領域 | 原生內容在 0／1／2 張手牌下皆可進行；不足兩張不應新增付款門檻 |
| 先獲得牌或其他收益 | 不屈意志、劍影・斷念、符文置換、元子重塑等 | 起始缺攻擊牌不能作為整項取消依據；不屈意志實測先付能量、抽牌、加劍氣、再加攻擊 |
| 追加行動伴隨其他效果 | 神聖追擊、瞬・影・殺、戾如泉湧、一擊無念、偷襲等 | 要保留治療、指示物、狀態或傷害部分；不能一律當成沒牌的空技能 |
| 轉換牌／延後判斷 | 虛榮掌握＋相思病、二重劍影、元素射擊等 | 需要追蹤實際轉換技能、觸發牌與判斷時點；不能只數實體牌名或自行猜系別 |
